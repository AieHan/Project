# 🔐 PassGuard - Advanced Password Strength Checker

## Description
An interactive web application that analyzes password strength in real-time, provides security suggestions, and generates strong passwords. Built as a cybersecurity awareness tool.

## Features
- ✅ **Real-time password strength analysis** (0-4 scale)
- ✅ **Detailed statistics** (length, uppercase, lowercase, numbers, symbols)
- ✅ **Issue detection** (common patterns, short length, missing variety)
- ✅ **Smart suggestions** for improvement
- ✅ **Strong password generator** (customizable length & character types)
- ✅ **Password history** (stores only strength scores, not actual passwords)
- ✅ **Dark mode** for comfortable use
- ✅ **Show/hide password** toggle
- ✅ **Fully responsive** (works on mobile, tablet, desktop)

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Gradients, Animations)
- JavaScript (ES6+)
- LocalStorage API

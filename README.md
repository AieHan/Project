# 🔐 PassGuard | Advanced Password Strength Analysis Tool

## 📌 Project Title
**PassGuard - A Real-Time Password Strength Checker with Security Recommendations**

---

## 📖 Description

PassGuard is an interactive web-based security tool designed to educate users about password security best practices. The application analyzes password strength in real-time using industry-standard criteria, provides actionable feedback for improvement, and includes a secure password generator.

This project was developed as part of the **CSD34203 - Individual Project Portfolio** course, demonstrating proficiency in front-end web development, cybersecurity awareness, and user-centered design.

The tool addresses a critical cybersecurity gap: according to recent data, **81% of data breaches are caused by weak or stolen passwords**. PassGuard empowers users to create and test strong passwords before using them on actual accounts.

---

## ✨ Features

### Core Functionality
| Feature | Description |
|---------|-------------|
| **Real-Time Password Analysis** | Instantly evaluates password strength as you type (0-4 scale) |
| **Detailed Statistics** | Displays character counts (uppercase, lowercase, numbers, symbols) |
| **Issue Detection** | Identifies common problems (short length, missing character types, predictable patterns) |
| **Smart Suggestions** | Provides specific, actionable recommendations for improvement |
| **Secure Password Generator** | Creates cryptographically strong passwords (8-32 characters, customizable character sets) |
| **Password History** | Stores masked passwords with strength ratings (actual passwords never saved) |
| **Dark Mode** | Toggleable dark theme with localStorage persistence |
| **Show/Hide Password** | Visual toggle for password visibility |

### Educational Content
- **Security Blog** - 4 in-depth articles on password security, 2FA, phishing awareness
- **FAQ Section** - Answers to common security questions
- **Contact Form** - User feedback and inquiry system

### Technical Features
- Fully responsive design (mobile, tablet, desktop)
- No external dependencies or frameworks
- Zero data transmission (all processing occurs locally in browser)
- LocalStorage API for user preferences and history
